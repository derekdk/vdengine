# VDE Games

This directory contains larger, multi-file game applications built on the VDE Game API.

Games differ from `examples/` by prioritizing a fuller gameplay loop and a multi-file layout, while still supporting the same scripted smoke-test workflow through `vde.toml` metadata and `.vdescript` scripts.

## Current games

- `fishing_game/` - 2D pond-fishing game showing the recommended `games/` layout
- `level_builder/` - Phase 1 tilemap baseline for the controller-driven level-builder workflow
- `pong/` - Classic one-player Pong showing the lightweight end of the `games/` structure
