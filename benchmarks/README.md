# benchmarks/

Holds per-run compile-time benchmark reports generated by
`scripts/benchmark-compile.ps1`.

Each file is named `<yyyyMMdd-HHmmss>-<label>.json` and contains
wall-clock compile times for every translation unit, broken down by
target (`vde`, `examples`, `tools`, `tests`, `deps`).

Files in this directory are **git-ignored** (machine-specific).
Use `scripts/compare-benchmarks.ps1` to diff two reports.

## Quick workflow

```powershell
# Baseline before any changes
.\scripts\benchmark-compile.ps1 -Label "baseline-headers"

# After experimental change (e.g. first module unit)
.\scripts\benchmark-compile.ps1 -Label "phase1-modules"

# Compare
.\scripts\compare-benchmarks.ps1 -Baseline baseline-headers -Candidate phase1-modules -Markdown
```

See `scripts/README.md` for full parameter reference.
