# Hex Editor

The Hex Editor is a viewer and inspection tool for binary files. It can open files, display their contents in hexadecimal and ASCII form, and help compare binary data to identify differences during debugging or content investigation.

This tool does not produce assets. It is intended for examining and comparing existing files rather than generating new output.
## Usage

### Interactive mode

```
vde_hex_editor
```

### Script mode

```
vde_hex_editor path/to/script.txt
```

## Commands

| Command | Description |
|---------|-------------|
| help    | Show available commands |

## Controls

| Key | Action |
|-----|--------|
| ESC | Exit |
| F1  | Toggle UI |
| F11 | Toggle fullscreen |
| Mouse drag | Rotate camera |
| Mouse wheel | Zoom camera |
